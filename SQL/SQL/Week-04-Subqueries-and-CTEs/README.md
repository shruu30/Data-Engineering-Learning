
# Week 4 - SQL Subqueries and CTEs

## Objective
Learn to write SQL queries using subqueries and Common Table Expressions (CTEs) to solve business and data engineering problems.

## Topics Covered
- Subqueries and nested queries
- Single-row and multiple-row subqueries
- Correlated subqueries
- IN, EXISTS, ANY and ALL
- Common Table Expressions (CTEs)
- Multiple CTEs
- Introduction to recursive CTEs
- Subqueries vs CTEs

- README.md

- SQL_Subqueries_CTEs.sql
- Practice_Questions.md
- Practice_Answers.sql
- Interview_Notes.md

## Practical Applications
- Identifying high-value transactions
- Comparing transactions against average amounts
- Finding customers with no accounts
- Identifying department-wise salary records
- Preparing data for ETL pipelines
